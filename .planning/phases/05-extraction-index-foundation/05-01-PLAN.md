  <action>
Create `app/plugins/doc_extraction.py` as a pure-function module with NO plugin dependencies (no imports from `app.plugins.base`, no FastAPI, no sqlite3). Imports: `logging`, `hashlib`, `xml.etree.ElementTree`, `charset_normalizer`, `pdfplumber`, `pypdf`, `docx` (python-docx), `doc2txt`, `docutils.core` + `docutils.io`.

Module-level logger: `logger = logging.getLogger("doc_extraction")`.

**Format dispatch table (module-level `EXTRACTORS` dict):**
```python
EXTRACTORS: dict[str, Callable[[str], str]] = {
    ".docx": extract_docx,
    ".pdf": extract_pdf,
    ".doc": extract_doc,
    ".rst": extract_rst,
    ".drawio": extract_drawio,
    ".graphml": extract_graphml,
}
```

**SHA-256 helper:**
`compute_sha256(file_path: str) -> str` — reads file in 64KB chunks via `hashlib.sha256()`, returns lowercase hex digest. Handles `FileNotFoundError` → `logger.warning` → returns empty string `""`.

**Encoding detection:**
`detect_encoding(text: str) -> str` — takes extracted text string, encodes to bytes as UTF-8 (with 'replace' for safety), passes through `charset_normalizer.from_bytes().best()`, returns the detected encoding name (e.g. "utf_8", "windows_1257"). If charset-normalizer fails to detect, returns `"utf_8"` as safe default. Logs a debug message with the detected encoding.

**6 extractor functions — each signature: `extract_xxx(file_path: str) -> str`:**

1. **extract_docx**: Uses `docx.Document(file_path)`. Iterates `doc.paragraphs`, extracts `para.text` joined by newlines. Also iterates `doc.tables` — for each table, iterates rows then cells, extracting `cell.text` joined by tabs per row. Returns combined text. Wraps in try/except: on any exception, `logger.warning("Failed to extract .docx: %s: %s", file_path, e)` and returns `""`.

2. **extract_pdf**: Primary: `pdfplumber.open(file_path)` → iterate `.pages`, extract `.extract_text()` or `""` per page, join with newlines. Catches `Exception` → falls back to pypdf: `pypdf.PdfReader(file_path)` → iterate `.pages`, `.extract_text()` per page, join. Catches all exceptions → `logger.warning` → returns `""`. After extraction: if `len(pdf.pages) > 0` but `len(text.strip()) < 20`, returns `""` (scanned PDF detection — the calling `extract_text()` wrapper handles the `needs_ocr` flag, see below).

3. **extract_doc**: Uses `doc2txt.extract_text(file_path)`. Wraps in try/except (including `ImportError` if antiword binary missing). On failure: `logger.warning("Failed to extract .doc: %s: %s", file_path, e)` → returns `""`.

4. **extract_rst**: Uses `docutils.core.publish_doctree(source=open(file_path).read())` to get a document tree, then recursively walks all nodes extracting `node.astext()` for Text nodes, joined by newlines. Wraps in try/except → `logger.warning` → returns `""`.

5. **extract_drawio**: Parses with `xml.etree.ElementTree.parse(file_path)`. Finds all `mxCell` elements with a `value` attribute, extracts `cell.get("value", "")` for each, joins by newlines. Wraps in try/except (including `ET.ParseError` for corrupt XML) → `logger.warning` → returns `""`.

6. **extract_graphml**: Parses with `xml.etree.ElementTree.parse(file_path)`. XML namespace: `ns = {"graphml": "http://graphml.graphdrawing.org/xmlns"}`. Finds all `graphml:node` elements, then for each finds `graphml:data` child elements, extracts `data.text or ""`, joins by newlines. Falls back to no-namespace search if namespace yields nothing. Wraps in try/except → `logger.warning` → returns `""`.

**Main dispatch function: `extract_text(file_path: str) -> dict`:**
```python
def extract_text(file_path: str) -> dict:
    """
    Returns: {
        "text": str,        # extracted text (empty on failure)
        "encoding": str,    # detected encoding (e.g. "utf_8")
        "needs_ocr": bool,  # True if PDF with pages>0 but text<20 chars
        "sha256": str,      # lowercase hex digest
        "error": str | None # error message if extraction failed, else None
    }
    """
```
Logic:
1. Compute `sha256` via `compute_sha256(file_path)`.
2. Determine extension via `os.path.splitext(file_path)[1].lower()`.
3. Look up extractor in `EXTRACTORS`. If extension not in table: return dict with `text=""`, `error=f"Unsupported format: {ext}"`.
4. Call extractor function in try/except: on exception → return dict with `text=""`, `error=str(e)`.
5. `text = raw_text.strip()`. Detect encoding via `detect_encoding(text) if text else "utf_8"`.
6. Determine `needs_ocr`: True only if extension is `.pdf` AND the original PDF page count > 0 AND `len(text) < 20`. For non-PDF files, always False.
7. Return the dict with all fields populated.

IMPORTANT: `extract_text()` must never raise an unhandled exception — the top-level try/except covers the extractor call AND the post-processing.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Denial of Service | All extractors | mitigate | Every extractor wrapped in try/except — malformed/corrupt files produce `logger.warning` + return empty string, never crash. No unbounded memory allocation: PDF pages iterated one at a time, XML parsed incrementally via ElementTree.iterparse equivalent (or parse entire tree — 3000 docs averaging 100KB is within memory budget). |
| T-05-02 | Tampering | extract_text() file_path | mitigate | Extraction functions are pure and only called with trusted paths from Phase 6's sync engine. Phase 6 adds `os.path.realpath()` validation before any extraction call. Phase 5 docstring notes this expectation. |
| T-05-03 | Information Disclosure | extract_text() output | accept | Extracted text contains whatever the source document contains — no sanitization at extraction layer. Phase 6 search API handles XSS sanitization of snippets/previews. Accepting this because extraction is a data layer, not a presentation layer. |
| T-05-SC | Tampering | pip installs (pdfplumber, pypdf, python-docx, doc2txt, docutils, charset-normalizer) | accept | All 6 packages verified during research phase (SUMMARY.md, Confidence: HIGH). python-docx (160M+ downloads), pypdf (200M+), pdfplumber (~50M), docutils (stdlib-adjacent, 20+ years), charset-normalizer (actively maintained by the requests ecosystem). doc2txt (most niche, ~500K downloads) was verified for bundled antiword Windows support. No slopcheck flags. |
